📐 几何严密推导原理
步骤 1 构建几何直角模型：
过交点 P(x, y) 向 x 轴引垂线，构成 Rt△OMP： 底边邻边长 OM = |x|，垂线对边高 MP = |y|，斜边半径恒为 OP = r = 1（单位圆）。
步骤 2 · 余弦证明 依据直角三角形余弦定义（邻边比斜边）：
cos α = 邻边斜边 = OMOP = x1 = x
即：横坐标 x 严格等价于角 α 之余弦值。
步骤 3 · 正弦证明 依据直角三角形正弦定义（对边比斜边）：
sin α = 对边斜边 = MPOP = y1 = y
即：纵坐标 y 严格等价于角 α 之正弦值。
终边单位圆交点恒表示为：P(x, y) ≡ (cos α, sin α)
1 设角归圆
基石原理
设 α 是一个任意角，它的终边与单位圆交于点 P(x, y)。
以坐标代几何：动点 P(x, y) 随角度旋转而移。
( 1 ) 正弦定义
对应纵坐标
y 叫做 α 的正弦，记作：
sin α = y
( 2 ) 余弦定义
对应横坐标
x 叫做 α 的余弦，记作：
cos α = x
( 3 ) 正切定义
斜率比值
yx 叫做 α 的正切，记作：
tan α = yx ( x ≠ 0 )
